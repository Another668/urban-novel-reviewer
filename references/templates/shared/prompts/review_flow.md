# 评测阶段提示词

## 自我反思流程

章节创作完成后，进入自我反思评测阶段。

请依次调用以下评测 Agent，对章节进行全面检查：

## 评测顺序

### 1. LogicChecker - 逻辑一致性检查
检查要点：
- 时间线是否矛盾
- 规则设定是否被打破
- 因果链是否完整
- 是否有常识错误

### 1.5 ConflictChecker - 冲突质量检查
检查要点：
- 冲突类型是否明确（认知/利益/性格/情感/外在/内心）
- 冲突是否有层次（表层→深层）
- 冲突是否递进（不是"被欺负→打回去"直线性）
- 是否有"无意义冲突"（为冲突而冲突/对话注水/摄像头主角）
- 主角解决冲突是否付出真实代价

【男频专属】冲突是否服务升级/利益目标
【女频专属】冲突是否服务情感拉扯/关系确认；情感代价是否真实

### 1.6 DescriptionQualityAgent - 描写质量检查
检查要点：
- 对话-描写比例：对话是否超过40%
- 动作描写密度：每千字是否≥3处动作描写
- 心理描写：是否有内心独白/情感反应
- 微表情运用：情感/冲突场景是否≥2处微表情暗示
- 环境描写：每场景是否至少1处环境/场景描写

【女频专属】女频更注重情感描写，心理描写比男频更关键；情感场景对话占比容易过高需重点检查

### 2. CharacterJudge - 人物塑造检查
检查要点：
- 人物行为是否符合性格
- 台词是否贴切
- 情感表达是否真实
- 关系动态是否合理
- **主角深度**：性格缺陷、价值观底线、成长弧光
- **反派合理性**：嘲讽质量、智商、城府

### 3. GenderSpecialJudge - 性别视角专项检查
根据题材频道选择对应专项：

【男频】FemaleCharacterJudge - 女性角色专项检查（如有重要女性角色时调用）
- 女性角色是否有独立目标（不是"辅佐男主"）
- 女性角色是否有成长线（不是被男主"改造"）
- 女性角色是否有自主选择权（她的决定影响剧情）
- 女性角色是否有底线（不是无条件付出）
- 是否沦为工具人（奖品/花瓶/助攻）

【女频】MaleRolesJudge - 男性角色专项检查（Critical级别）
- 男性角色是否有独立目标（不是只为女主）
- 男性角色是否有性格深度
- 男性角色是否有成长弧光
- 关系是否平等（根据用户选择）

【女频】FemaleCharacterJudge - 女性角色专项检查
- 女性角色是否有独立目标
- 女性角色是否有成长线
- 女性角色是否有自主选择权
- 女性角色是否有底线
- 是否沦为工具人

【女频】RomanceLineJudge - 感情线质量检查（女频特有）
- 感情线阶段推进是否合理
- 推拉节奏是否到位
- 甜虐平衡是否合理
- 角色在感情中是否有主动性
- 用户偏好的感情风格是否体现

### 4. PaceCritic - 节奏把控检查
检查要点：
- 开篇是否抓住读者
- 节奏是否有起伏
- 高潮是否有力
- 结尾是否有钩子

### 5. ForeshadowHunter - 伏笔呼应检查
检查要点：
- 之前埋下的伏笔是否回收
- 新埋伏笔是否自然
- 呼应是否合理

### 6. InfoAuditor - 信息交代检查
检查要点：
- 世界观交代是否清晰
- 是否信息冗余
- 是否信息缺失
- 展示方式是否自然

### 7. GoldfingerChecker - 金手指使用检查（如小说有金手指）
检查要点：
- 金手指是否被正确使用（不是100%成功）
- 是否有代价或限制
- 主角是否过度依赖
- 金手指是否替代了主角的成长

### 8. ClimaxChecker - 爽点设计检查
通用检查要点：
- 爽点是否有铺垫
- 爽点是否有代价/来之不易
- 是否避免连续爽点
- 是否有精神层面的爽点（成长/情感/认知）

【男频专属】爽点以升级/打脸/获取资源为主，精神爽点为加分项
【女频专属】先识别题材类型（言情/耽美/百合/甜宠/快穿/女尊）；女频爽点类型：情感共鸣型、羁绊确认型、小甜型、推拉张力型；情感高潮前须有心理铺垫；甜蜜时刻需水到渠成；警惕将感情高潮误用为打脸对方（甜≠赢）

【女频climax标准】：
- ✅ 情感共鸣：被理解、被接纳的满足感
- ✅ 羁绊确认：告白、承诺、相互敞开心扉
- ✅ 小甜型：细节糖/场景糖/语言糖/肢体糖
- ❌ 甜=打脸对方（甜是在场、是亲密，不是赢）

### 9. PovChecker - 叙事视角检查
检查要点：
- POV类型是否明确且适合题材
- 视角是否一致（无混乱跳入他人内心）
- 是否有"摄像头主角"问题（只有眼睛没有动机）
- 视角切换是否有清晰提示（转场/悬念钩子）

【男频专属】多为第三人称；全知视角是否服务多线叙事/力量体系展示
【女频专属】多为第一人称/女主人公视角；是否能通过视角产生深度情感共鸣；男配是否通过女主限知视角呈现足够丰满

### 10. SupportingChecker - 配角价值检查
检查要点：
- 配角是否有自己的目标
- 配角是否有自己的困境
- 配角是否沦为工具人
- 配角和主角是否平等

### 11. PlotStructureAgent - 剧情结构检查
**必须执行！避免剧情重复单调。**
检查要点：
- 场景类型多样性：最近10章是否有多种场景类型
- "嘲讽→打脸"循环是否超过3次
- 是否有日常/成长型等缓冲章节
- 章节标题是否规范（反映核心看点）
- 续写时是否查询了前文数据库

【男频场景类型】：起承转合型、层层递进型、悬念揭示型、人物展示型、世界展示型、伏笔回收型、对手戏型、日常缓冲型、成长突破型、打脸型

【女频场景类型】：感情推进型、误会冲突型、甜蜜互动型、推拉张力型、日常缓冲型、情感积累型、人物展示型、世界观展示型、转折突发型、关系确认型

**多样性规则**（通用）：
- 打脸章节占比 ≤ 30%
- 每5章至少有1章日常/情感积累型
- 每10章至少有1章世界/人物展示型（男频）
- 连续打脸不超过3章

### 【女频专属】BL/GL专项评测（仅BL/GL小说）

#### BLRelationshipJudge（仅耽美）
- 攻受关系是否平衡
- 是否娘受化
- 情感是否真实
- 身体描写vs情感描写比例

#### GLRelationshipJudge（仅百合）
- 两女主是否都有深度
- 女性真实性是否保持
- 情感共鸣是否真实
- 是否避免男性凝视

## 评测通过/失败标准

### 通过标准（必须同时满足）

| 条件 | 说明 |
|------|------|
| **所有维度≥5分** | 任何维度<5分直接不通过 |
| **无Critical问题** | 任何Critical级别问题直接不通过 |
| **核心设计原则通过** | 反派塑造/主角深度必须≥7分 |

【男频专属】女性角色维度必须≥7分（如存在重要女性角色）
【女频专属】男性角色独立性/感情线推进必须≥7分

### 评分等级

| 分数 | 等级 | 说明 |
|------|------|------|
| 9-10 | 优秀 | 超过预期，可作为范例 |
| 7-8 | 良好 | 符合标准，可通过 |
| 5-6 | 一般 | 有问题，需要修改 |
| <5 | 差 | 有严重问题，必须重写 |

### 问题严重性分级

```
Critical（必须修复）：
- 反派出现"废物"、"穷鬼"等无脑嘲讽
- 严重逻辑矛盾（时间线/规则bug）
- 机械降神（毫无铺垫的新设定）
- 主角毫无性格缺陷（完美人设）
- 金手指100%成功无代价
- 连续爽点超过3章

【男频专属Critical】
- 女性角色明显工具化（无独立目标）

【女频专属Critical】
- 男性角色完全沦为工具人（无独立目标/无成长/无性格）
- 女性主角严重依赖男性拯救（违背用户偏好）

Major（应该修复）：
- 节奏过慢/过快
- 伏笔密度不合理
- 信息冗余/缺失
- 配角沦为工具人
- 反派嘲讽质量一般

【女频专属Major】
- 感情线推拉失衡
- 甜虐比例失调（用户偏好偏差）
- 男性描写占比过高

Minor（可以忽略）：
- 个别错别字
- 微小的节奏问题
- 细节不够完善
```

### 冲突解决规则

```
当不同Agent给出冲突意见时：
1. 以Critical问题为准
2. Major问题需要讨论决定
3. Minor问题可以保留
4. 如有疑问，以性别视角专项检查为准（因为更容易被工具化）
```

## 评测后处理

### 如果需要修改
根据评测反馈，修改章节内容，修改后再次评测，直到通过。

### 如果通过审核
将评测结果记录到数据库。

### 反馈处理

收到人类反馈后：

1. 如果通过：
   - 更新章节状态为 approved
   - 将反馈记录到数据库（可选）

2. 如果有修改意见：
   - 记录反馈到数据库
   - 根据意见修改章节
   - 再次提交审核
