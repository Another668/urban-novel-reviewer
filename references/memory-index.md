# 记忆文档索引系统（Memory Index）

审稿技能的"记忆底座"。解决长篇连载审稿中"记不住设定、数值穿帮、伏笔遗忘、人设走形"四大问题。

---

## 一、文档识别规则（自动扫描）

审稿启动时，在**项目根目录**按以下优先级扫描，命中即纳入记忆底座：

### 1. 真相/记忆文档（最高事实源）

| 文件名模式 | 识别为 | 用途 |
|-----------|--------|------|
| `*真相*`、`*记忆文档*`、`*truth*` | 全书真相文档 | 人物/数值/物品/伏笔/已确认事实总库 |
| `story_bible.md` | 世界观设定库 | 世界观、势力、规则 |
| `current_state.md` | 当前状态 | 地点/时间/人物当前状态 |
| `pending_hooks.md` | 伏笔账 | 待回收伏笔 |
| `handoff_current.md` | 会话交接 | 跨会话进度 |
| `progress_tracker.md` | 进度面板 | 字数/章节偏离 |
| `chapter_summaries.md` | 章节摘要 | 前文回溯 |
| `character_matrix.md` | 角色矩阵 | 关系/信任/信息边界 |
| `character_knowledge.md` | 知识边界 | POV管理 |
| `emotional_arcs.md` | 情感弧线 | 好感度曲线 |
| `pattern-detection.md` | 循环模式 | 桥段克隆检测 |

### 2. 大纲文档

| 文件名模式 | 识别为 |
|-----------|--------|
| `大纲/` 目录下全部 `.md` | 总纲/卷纲/章纲 |
| `*大纲*`、`*卷纲*`、`outline.md` | 大纲 |

### 3. 社交设定文档（setting/ 目录）

| 文件 | 用途 |
|------|------|
| `character_social.md` | 人物社交人格卡 |
| `relationship_map.md` | 人物关系与利益图谱、人情账本 |
| `social_scenarios.md` | 场景社交规则库 |

### 4. 正文章节

| 路径模式 | 用途 |
|---------|------|
| `正文章节/*.txt`、`章节/*.txt`、`chapter*.txt` | 被审对象 + 跨章对比源 |

> 扫描不到某类文档时不报错，跳过对应核验维度并在报告"记忆底座"部分声明缺失。

## 二、本章索引锚点提取模板

读取记忆文档后，**针对被审章节**提取以下锚点（只提取与本章相关的，控制篇幅）：

```markdown
## 本章记忆锚点（审稿前必读）

**章节定位**：第X章 · 大纲节点名 · 节奏要求（快/中/慢）
**本章大纲目标**：[从卷纲提取：核心冲突、爽点埋设/回收、情感变化]

### 出场人物档案
| 人物 | 本章应有的状态 | 语言指纹（口癖/句式） | 灵魂铁则（不可违反项） |
|------|--------------|-------------------|---------------------|
| 例：张凯 | 护妻值+10，嘴硬值98趋降 | 短句/命令式/"老子""闭嘴" | 身体先动/占有欲/嘴硬心软 |

### 数值前值（本章开场时应为）
- 系统点数：[名称] = X
- 好感/心动类数值：[角色对角色] = X
- 等级/阶位：第X阶
- 本章若产生数值变动，记录变动量与播报原文，审后核对累计是否正确

### 在途任务
| 任务名 | 状态 | 要求 | 奖励/惩罚 |
|--------|------|------|----------|

### 物品/技能账
- 本章应持有物品：[...]
- 本章应已解锁技能：[...]
- 预告但未解锁的（不得提前出现）：[...]

### 伏笔账
- 本章应埋设：[伏笔#X，来源大纲]
- 本章应回收：[伏笔#X，埋设章]
- 待回收且本章不得遗忘的线索：[...]

### 已确认事实（红线，本章不得违反）
- [逐条列出与本章场景相关的不可打破设定]
```

## 三、一致性核验清单（D2连载一致性维度逐项执行）

审稿时逐条打勾，每条指控必须给出"文档记录 vs 正文写法"的对照：

### 1. 数值核验
- [ ] 系统点数/货币：本章开场值 = 上一章收尾值？获得/扣除后累计计算正确？
- [ ] 好感/心动类数值：增量合理（与情感事件强度匹配）？累计无跳变？播报格式统一（"增量+当前值"）？
- [ ] 等级/阶位：未发生晋升事件时不得跳阶？晋升所需点数与进度匹配？
- [ ] 数值播报原文与追踪表一致？

### 2. 人物核验（OOC）
- [ ] 对话符合语言指纹（口癖出现/句式长短/语气词）？
- [ ] 行为符合灵魂铁则（对照人物卡逐条）？
- [ ] 情绪反应与"情绪反应库"不重复克隆？
- [ ] 性格转变有触发事件铺垫，无突变？
- [ ] 角色知识边界：不该知道的信息没有被角色"未卜先知"？

### 3. 物品/技能核验
- [ ] 本章使用的物品均在"持有清单"内（未获得的不得凭空出现）？
- [ ] 已消耗/失去的物品不再被使用？
- [ ] 预告技能未提前解锁？已解锁技能效果与设定描述一致？
- [ ] 道具功能与记忆文档记载一致（未被临时加强/弱化）？

### 4. 伏笔核验
- [ ] 大纲要求本章埋设的伏笔已埋？埋设方式是否隐蔽（不直白点破）？
- [ ] 大纲要求本章回收的伏笔已回收？回收方式与埋设呼应？
- [ ] 待回收伏笔有无超期遗忘（对照预计回收卷/章）？
- [ ] 回收时不与前文埋设细节矛盾？

### 5. 已确认事实核验（红线）
- [ ] 本章涉及的人物基础设定（身高/年龄/身份/身体特征）与事实库一致？
- [ ] 场景/制度设定（地点名/规则/院系）一致？
- [ ] 系统机制（触发条件/惩罚规则/系统音风格）一致？
- [ ] 无"事实库明确记载为A，正文写成B"的硬伤？

### 6. 时间线核验
- [ ] 本章时间承接上一章（日期/时段/季节）？
- [ ] 章内时间流逝合理（路程/事件耗时/作息）？
- [ ] 角色年龄/年级随时间推进正确？

## 四、记忆文档滞后处理

当记忆文档进度 < 被审章节进度时：

1. 报告开头标注滞后警告（见主文件第1步）。
2. 数值/伏笔类判断改为**正文回溯法**：从最近的已写章节中提取上一状态值，顺推核对本章，不引用滞后的文档数字。
3. 审稿报告末尾追加"**记忆文档待更新清单**"：
   - 本章新产生的数值/物品/技能/伏笔/关系变化
   - 建议按记忆文档的板块格式（作精值表/心动值表/伏笔追踪器等）补录
   - 提供可直接粘贴的更新草稿，但标注"请作者确认后写入"

---

## 五、索引效率原则

- 锚点提取**只取本章相关**：出场人物、本章场景涉及的设定、在途任务、本章伏笔。无关人物卡和远期设定不加载。
- 大型真相文档（如13板块全库）用"目录速览表"定位板块，只精读相关板块，不全书复述。
- 跨章对比审时，加载被审章节区间的章节摘要 + 区间首尾的数值状态，中间章节按问题线索回溯。
