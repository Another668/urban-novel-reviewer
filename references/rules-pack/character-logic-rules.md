## 一、逻辑结构审查（B1 情节合理性 / B2 时间线 / B3 连贯 / B4 视角）

### 1.1 因果链（番茄伪代码流程，逐场景执行）

1. 遍历场景转换：无因果连接 → 🔴 **场景跳脱**（反例：茶馆喝茶，下一段突然出现在废弃工厂），要求补过渡句或因果事件；
2. 遍历"突然/然后/就在这时"：前后无因果 → 🟡 **虚假连接词**，补因果或删连接词；
3. 主角每个重要行为须有前文可追溯动机：突发重大决定无铺垫 → 🔴；
4. 新角色/新道具出场须有前置铺垫；无铺垫的高潮 = 🔴，铺而不发 = 🟡；
5. **上帝之手**：反派突然犯蠢、巧合连发（>2 次/章）、危险无故消失 → 🔴/🟡。

### 1.2 时间线硬规则

- 标记全部时间词（昨天/三年前/子时/三点钟）验证自洽；
- **时间黑洞**：时间跳跃 >1 小时且无中间事件交代 → 🔴（反例：11 点到小区，凌晨 3 点才进楼，中间 2 小时无事件）；
- 年龄/成长与经历匹配；同段落季节一致（深冬大雪后几段柳絮飘飞 = 🔴）；
- 故事内时钟速度合理（早上出发中午到却"千里之遥" = 🔴）；
- 无明确时间信息时不硬判，默认 8 分。

### 1.3 上下文连贯

- 设定连贯：已确立规则/道具/地点正确延续（"只有传承者能拔出的剑"被人随手拿起 = 🔴）；
- 状态连贯：上章重伤昏迷本章开头跑步训练无交代 = 🔴；
- 情绪承接：亲人刚死下一段开玩笑无过渡 = 🔴；
- 信息连贯：前文偷听到密谋，后文见反派毫无防备 = 🔴；
- **行为-规则一致性**（系统文/规则怪谈/异能文必查）：提取每条规则声明 → 遍历后续行为 → 违反且无解释 = 🔴（反例：规则说"灯闪时不要移动"，主角直接走出）。

### 1.4 视角（POV）

- 视角越界：限知视角写出视角人物不可能知道的信息（"他不知道王强正在三楼准备陷阱" = 🔴）；
- 读心：直接获知他人内心而非观察推测（"她心里很害怕" → 应写"手指在桌子下攥得很紧"）；
- 无预告切换：未用分节线/空行直接换视角人物 = 🟡。

### 1.5 剧情张力五维（plot-tension-review，1-10 分/维，输出 Top3 问题）

| 维度 | 权重 | 检查要点 |
|---|---|---|
| 冲突强度 | 25% | 核心冲突明确；对抗方有压迫感；主角面临实质损失风险 |
| 节奏控制 | 20% | 信息密度均匀；无 ≥500 字无推进铺垫/回忆/说明；场景切换利落 |
| 悬念钩子 | 20% | 有明确钩子；伏笔隐蔽有效；章末留翻页动力 |
| 因果链条 | 20% | 事件有必然逻辑；动机充分；无强行推进感 |
| 情绪起伏 | 15% | 情绪随情节波动；高潮有释放；无情绪平流区 |

Top3 问题每个必含：**问题位置（段/行）+ 问题本质（一句话）+ 2-3 种可执行修改方案 + 预期效果（提升哪维/约 +X 分）**。禁止"增加冲突""加快节奏"空话。

水检测 6 信号：全章对话无新信息；同一情绪写 ≥3 段；场景描写 >500 字不推进；回忆无新视角；连续 2 章以上无冲突；删掉无损的流程细节/卡点。
节奏红线：连续 5000 字无爽点预警；连续 2 章压力级 ≤1 或相邻章情绪趋同 = 🔴；一卷内低压+过场章合计 ≤15%。

### 1.6 公路节点节奏模型（v3.6.0 新增，公路求生 / 线性推进题材专属标准）

【适用范围】仅激活于公路求生、线性推进类题材（以载具移动为核心叙事，命中 system-novel-rules #21 公路求生·克苏鲁向模板时默认适配）；非公路题材不适用本节，仍按 §1.5 通用张力标准。
【核心逻辑】以公路里程为叙事轴线，采用「日常行驶段 + 节点事件段」张弛交替结构，节点密度与危险梯度正相关。本节为 C1 节奏爽点维度的题材专属量化标准，与 G6 节奏门禁配合使用。

**标准节点分级与间隔**：

| 节点等级 | 间隔章数 | 内容占比 | 核心功能 |
| --- | --- | --- | --- |
| 小型节点（服务区/加油站/废弃车辆） | 3~5 章 | 1~2 章 | 补给 + 小规模冲突 + 浅层线索，调节节奏 |
| 中型节点（废弃小镇/隧道/检查站） | 8~12 章 | 3~5 章 | 中等危险 + 关键线索 + 载具小幅升级，推进主线 |
| 大型节点（核心污染区/公路枢纽/真相点） | 25~35 章 | 5~10 章 | 高强度危机 + 核心剧情揭露 + 载具重大升级，阶段高潮 |

**节奏配比标准**：
- 日常行驶段：节点事件段 ≈ **3:1**，保证公路移动感与生存压迫感；
- 日常行驶段功能：资源消耗、状态描写、氛围铺垫、小冲突触发（非水章，删不掉信息）；
- 节点事件段功能：集中冲突、线索回收、奖励发放、剧情推进；
- 禁止连续 2 个及以上高密度节点，禁止连续 10 章以上无事件纯行驶。

**危险梯度校验标准**：
- 节点危险度与累计行驶里程严格正相关，越往公路深处难度越高；
- 前期节点以生存威胁为主（资源短缺、普通异常），后期加入认知污染、规则扭曲；
- **载具强度提升速度 ≤ 危险提升速度**，禁止载具升级后碾压一切（联动 system-novel-rules #21 载具升级机制）；
- 每个节点必须同时包含「风险 + 收益 + 线索」三要素，缺一即为结构缺陷。

**节奏异常判定标准**：
- 【过密预警】10 章内出现 2 个及以上中型节点 → 🟡 节奏过密，读者疲劳；
- 【过疏预警】连续 15 章无有效节点事件 → 🔴 节奏拖沓，剧情停滞；
- 【失衡预警】节点只有战斗无补给、或只有福利无危险 → 🟡 结构失衡；
- 【移动性丧失预警】连续 20 章以上停驻同一地点建基地经营 → 🔴 题材跑偏（公路文变定点末世文，联动 system-novel-rules #21 崩盘点⑤）。

## 二、人物塑造审查（C2：降智 / OOC / 一致性）

### 2.1 利益校准四步链（social-intelligence 核心，逐人物重大决策过筛）

**利益 > 立场 > 情绪 > 对错**：

1. **利益层**：决策触碰人物"核心利益底线"而无补偿 → 🔴 降智；与"可交易项"冲突但有等价交换 → 合理；
2. **立场层**：行为违背所属阵营共同利益且无倒戈铺垫 → 🔴；临时盟友必须以"共同敌人 + 实在利益"为基础，空口承诺不算数；
3. **情绪层**：情绪反应须符合"情绪伪装模式"——城府型角色当场爆发、无延迟无掩饰 → 🟡 OOC；
4. **对错层**：人物不能仅因"对错/正义"做出违背利益立场的事，除非人格卡写明该价值观；配角/反派禁止为配合主角而自我牺牲。

### 2.2 降智/送人头判定

- **反派送人头特征**：掌握优势/证据却不当场使用；无试探直接翻脸；底牌全盘托出；害人留下实据；BOSS 被三句话说服（话疗，见平台门禁包）；
- **配角降智特征**：为配合主角做违背自身利益的决策；知道关键信息却莫名不说/莫名全说；被低级话术轻易套话；
- **豁免**：决策符合人格卡"可交易/可让步项"、有等价筹码、或城府角色的退让伴随留后路/撇责任表述（"别说是我提的""成不成看你自己造化"）。

### 2.3 OOC 分级（与向量库人物档案联动）

- 违反灵魂铁则 = 🔴；语言指纹漂移、情绪反应连续 ≥3 次克隆 = 🟡；
- 性格标签逐场景验证：冷静沉稳者遇小事失控、刚正不阿者无铺垫为利益妥协 = 🔴；
- **成长弧豁免**：成长方向上的变化进"成长候选"不误判；心理转变须有触发事件，转变太快（<3 章）或毫无变化 = 🟡；
- 好感度双轴（感情线）：CP 行为按好感度 × 关系阶段双轴、**按低的一方计算**；好感度不足写亲密行为 = 油腻/性骚扰感 🔴/🟡；好感度进度须可感知。

### 2.4 社交段位匹配

- 段位词表：小白 / 老油条 / 城府极深 / 八面玲珑；
- 高位者：话不说满、留后路、撇责任、不轻易承诺、当众留体面 → 把话说满/轻易承诺 = 🟡；
- 小人物：可直来直去、口语化；
- 低位者抢高位者话头、当众打脸（除非打算彻底撕破脸）= 🟡；
- 全员话术绕弯程度一致 = "全员人精"失真 🟡；
- 当众/私下态度差异须合理。

### 2.5 读者契约审查（story-review，都市文差异化重点）

- **主角代理权四问**：谁决定事情为何发生？谁作不可替代选择？谁承担关键后果？核心收益结算给谁？——四问有 ≥2 问答"配角/系统/巧合/机构" → 🔴 主角边缘化；
- **期待债**：埋给读者的期待是偿还/延期付息/被吞掉？被吞掉（挖了不填）= 🔴；
- **终局储备**：宿敌/真相/身份/金手指上限是否提前动用？
- **自愿让渡红灯**："长期净收益为负 + 控制权/因果权下降"同时出现 = 主角被动 🔴；
- **黄金三问**（任何 finding 的前提）：①读者为什么翻下一页？答不出 ≥🟡；②本章改变了什么（目标/风险/信息/关系/资源/身份/情绪七选一，至少一项）？否则 ≥🟡；③证据呢？无原文引用不输出问题。

### 2.6 SAN 值状态行为校验规则（v3.6.0 新增，克苏鲁 / 诡异污染题材 OOC 专项补充）

【适用范围】仅激活于含克苏鲁 / 诡异污染 / SAN 值设定的题材，公路求生·克苏鲁向题材（system-novel-rules #21）默认适配；无 SAN/理智值设定的题材不适用本节。
【判定优先级】高于通用 OOC 判定规则：**因 SAN 值衰减导致的行为偏差，符合下列分级标准的，不判定为人物 OOC**（与 §2.3 成长弧豁免同属"合理变化不误判"原则）；分级之外的行为突变仍按通用 OOC 规则判罚。

**1. 轻度污染（SAN 值：90~70）**
- 认知状态：轻微影响，理智基本在线，自身可察觉异常；
- 合理行为（不判定 OOC）：偶发幻听、看错东西，下意识揉眼睛、怀疑自己疲劳；烦躁、焦虑、注意力下降，出现小幅操作失误；对诡异现象产生不安感，做出谨慎、回避的决策；开始下意识遵守未知规则，有怀疑但选择保守执行；
- OOC 判定红线：出现明显认知错乱、行为失控；性格底色 180 度反转（如原本冷静直接变恐慌失措）。

**2. 中度污染（SAN 值：70~40）**
- 认知状态：理智受明显影响，出现认知偏差，判断能力下降；
- 合理行为（不判定 OOC）：持续性幻视、幻听，分不清现实与错觉；行为偏执、固执，出现无意义的重复动作；情绪波动剧烈，易怒或过度恐惧，做出冲动决策；对公路规则产生病态执念，严格遵守甚至过度执行；记忆出现碎片、断层，对刚发生的事记忆模糊；
- OOC 判定红线：完全丧失逻辑思考能力，全程胡言乱语；核心行事原则彻底颠覆（如原本保命优先主动冲向危险）。

**3. 重度污染（SAN 值：40~10）**
- 认知状态：理智濒临崩溃，认知严重扭曲，现实感丧失；
- 合理行为（不判定 OOC）：出现大量幻觉，把现实物体看成诡异事物；行为失控，做出自残、狂奔、嘶吼等反常举动；认知逻辑完全扭曲，按照被污染的规则理解世界；对周围人产生敌意或过度依赖，判断完全失效；
- OOC 判定红线：保持完全清醒理智，行为和正常状态无差别；还能进行精密计算、复杂布局等高理智行为。

**4. 失控同化（SAN 值：10 以下）**
- 认知状态：自我意识消解，被公路 / 诡异力量同化；
- 合理行为（不判定 OOC）：机械性重复动作，失去自主意识；成为公路规则的一部分，攻击其他幸存者；完全失去人类认知，行为向诡异存在靠拢；
- OOC 判定红线：突然恢复理智，自行挣脱同化状态（无外力干预情况下）。

**补充校验规则**：
- SAN 值变化必须有诱因（接触诡异事件、进入污染区、违反规则、使用异常道具），**禁止无故掉 SAN、无故恢复**；诱因时间线与伏笔台账 F24/F27 接触史互证（见 foreshadow-topic-templates §二.6）；
- 恢复速度必须远慢于衰减速度，安全区、特定道具、睡眠仅能缓慢恢复，**禁止秒回满**；
- 人物核心底色（善良/自私、谨慎/莽撞）在轻度、中度污染中应保留残留，重度污染才可完全颠覆；
- SAN 分级与数值必须对应：正文声称"SAN 值还剩 80"却出现重度幻觉行为 = 数值穿帮，判 D2；正文无任何数值/状态交代却突然行为异化 = 无诱因 OOC，判 C2。

## 三、人情账本审计（D1，与向量库 social_ledger/relations 联动）

每章审后提取四类事件并回写，审稿时反向核对：

1. **人情往来**：债权人 → 债务人，等级 = 轻微/一般/重大/救命；**人情轻重须匹配事件重量**（救命级人情换小忙 = 🔴 人情失重；小题大做 = 🟡）；
2. **好感/猜忌变化**：建议幅度——重大人情 +15~25、一般 +5~10、猜忌事件 +10~20、撕破脸归零并标记；
3. **立场/阵营变动**：站队、倒戈、结盟须有铺垫；
4. **矛盾升级/缓和**。

核对规则：求人/帮忙/欠/还逻辑自洽；**没有无缘无故的善意或恶意，所有立场皆有原因**；还人情讲究"找借口"、有来有往（单向受惠无回请无欠账记录 = 🟡 关系失衡）。

后置审计 15 项清单见 [social-audit-checklist.md](social-audit-checklist.md)；场景话术规则见 [social-scenario-rules.md](social-scenario-rules.md)；人格卡/关系账本模板见 `references/templates/shared/templates/social_persona_card.md` 与 `references/templates/shared/templates/relationship_ledger.md`。
