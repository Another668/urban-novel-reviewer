# 性别转变角色专项审稿规则与模板库（v3.3.0 新增 · v3.3.1 兼容升级）

v3.3.0 新增。性别转变类题材（性转 / 变嫁 / 女装大佬 / 强制型性转 / 渐变式变性）的专项规则，**属于「人物逻辑审查」下的独立子插件**，**不替代通用审查**，**通用规则优先级高于专项规则**；复用原有 **OOC 校验 / 剧情张力 / 设定自洽** 三大核心能力，同时在心理-行为-生理-社交四维上提供分阶段、分赛道、分模板的对标参照。**两个加载入口**：

1. **大纲 / 设定稿加载**：识别到「性转 / 性别转换 / 变身 / 男变女 / 女变男 / TS / 女装大佬 / 伪娘 / 男娘 / 变嫁 / 嫁人 / 女体化 / 男体化 / 一觉醒来变了 / 系统强制变身 / 诅咒变性 / 慢慢变成女生 / 慢慢变成男生」等任一关键词（参见 [SKILL.md](../../SKILL.md) 意图词典）时，按本规则在 大纲分支的「基础逻辑审查」和「前瞻风险审查」中叠加专项审查；
2. **正文稿联动加载**：成稿章节出现性别转变场景、性别反差行为、周围人反应、身份暴露与重构、情感线推进等内容时，随 [character-logic-rules.md](character-logic-rules.md) 同步加载，**OOC / 行为逻辑穿帮判 C2，剧情利用 / 主线关联判 C4，设定自洽判 C1**；
3. **启用门槛（v3.3.1 兼容）**：需通过「**双重触发校验**」——① 命中关键词；② 上下文确认为性转题材（出现性别转变情节 / 人物设定含性别转换 / 作者明确要求性转专项审）。当题材识别性转置信度 **< 70%** 时，**自动降级为通用人物审稿**（character-logic-rules），不加载本规则。作者可通过「**启用性转专项审查**」「**禁用性转专项，按通用标准审**」两条手动开关指令直接切换。

## 二、分赛道审查标准与常见崩盘点

### （一）按转变模式分类

#### 1. 硬性转（瞬时转变）

- **定义**：一觉醒来 / 意外触发 / 系统强制，瞬间完成性别转换，无过渡过程。
- **审查标准**：
  1. 开篇必须有强烈的冲击感与否认期，禁止「坦然接受」式秒适应；
  2. 前 3–5 章重点描写生活混乱与生理不适，快速建立性别反差认知；
  3. 核心人设保留，仅行为模式受身体与环境约束发生变化；
  4. 必须有「掩盖身份 → 被发现 → 身份重构」的剧情节点。
- **常见崩盘点**：转变后立刻完全适应（无惯性残留）；核心人设崩塌（冷静→傻白甜、杀伐→矫情）；性取向同步突变无挣扎；周围人毫无惊讶感。
- **审稿校验清单**：有没有否认期？有没有旧行为惯性？核心性格是否保留？周围人反应是否合理？

#### 2. 渐变式性转（缓慢转变）

- **定义**：通过药物、系统、诅咒、血脉觉醒等方式，逐步发生性别特征变化，周期从数天到数月。
- **审查标准**：
  1. 分阶段体现身体变化：细微特征改变 → 第二性征明显 → 完全转变；
  2. 心理同步渐变：疑惑 → 焦虑 → 抗拒 → 挣扎 → 接纳 / 崩溃；
  3. 行为习惯逐步修正，随身体变化自然调整，非突然切换；
  4. 有主动掩盖 / 寻求解决的剧情动作，符合人物求生欲。
- **常见崩盘点**：阶段划分模糊，变化节奏混乱；身心变化不同步；全程被动接受。
- **审稿校验清单**：阶段是否清晰？身心变化是否同步？有没有主动应对行为？转变节奏是否稳定？

#### 3. 女装大佬 / 伪娘（非完全性转）

- **定义**：生理性别为男，着装 / 外在表现女性化，核心身份认同仍为男性，部分伴随身份认同动摇。
- **审查标准**：
  1. 初始动机明确（任务 / 赚钱 / 爱好 / 躲避追杀等），禁止无理由穿女装；
  2. 初期有强烈的违和感与羞耻感，动作僵硬，细节真实；
  3. 核心身份认同为男性，行为逻辑仍以男性思维为底色；
  4. 女装状态与日常状态有明确的行为差异，形成反差感。
- **常见崩盘点**：一穿就变「真女生」；羞耻感缺失；男装状态人设消失。
- **审稿校验清单**：初始动机是否成立？羞耻感与违和感是否体现？双状态人设是否统一？

#### 4. 变嫁文（性别转变 + 婚姻身份双重转变）

- **定义**：男转女后，最终与男性角色建立情感关系并成婚，是性转文的进阶分支。
- **审查标准**：
  1. 必须先完成性别身份接纳，再进入情感线，禁止顺序颠倒；
  2. 情感转变有铺垫：排斥男性接触 → 对特定人改观 → 产生依赖 → 接受情感；
  3. 婚姻身份转变有心理挣扎：从「我是男人」到「我是他的妻子」的身份重构；
  4. 男主（CP 方）人设独立，不是工具人，情感双向奔赴。
- **常见崩盘点**：刚变性别就爱上男人；全程被动接受；男主脸谱化；婚姻身份转变突兀。
- **审稿校验清单**：身份接纳与情感线顺序是否正确？情感转变有没有铺垫？婚姻身份有没有重构过程？CP 人设是否独立？

### （二）按性别方向分类

#### 1. 男频主流：男 → 女

- 核心看点：身份落差、男性思维在女性身体里的碰撞、社会角色反转。
- 审查重点：男性思维惯性残留、生理差异挫折感、社会对女性的约束与偏见。
- 避坑点：避免过度福利化、避免弱化主角智商、避免刻板化女性行为。

#### 2. 女频主流：女 → 男

- 核心看点：男性社会的生存法则、女性视角下的男性世界、力量感与身份解放。
- 审查重点：女性思维残留、男性社交规则不适、体力与力量变化适应、性别特权认知。
- 避坑点：避免纯开后宫爽文、避免男性气质刻板化、避免完全丢失原女性人格特质。

## 三、全类型转变过程模板库（审稿对标用）

> **通用五阶段底层框架（所有类型基础参照）**：所有性别转变过程均遵循「冲击 → 抗拒 → 适应 → 接纳 → 整合」五阶段递进，禁止跳步；阶段可快可慢，但不可缺失。命中以下模板时，按其「心理 / 行为 / 生理 / 社交 / 典型剧情点」对标，偏离过大即判崩盘点。

### 模板 1：男转女 · 硬性转 完整转变模板

#### 阶段一：冲击与否认期（第 1–3 章）

- **心理活动**：难以置信 → 自我欺骗 → 恐慌崩溃，坚信是梦 / 恶作剧，反复验证。
- **行为习惯**：
  - 男性惯性动作：走路大步流星、坐姿叉腿、说话大嗓门、下意识护裆、遇危险想硬刚；
  - 动作失误频繁：撞到门框、踩空、平衡感差、手脚不协调；
  - 刻意回避镜子、回避身体接触，试图用宽松衣服掩盖身形。
- **生理反应**：眩晕、乏力、体力断崖式下降、疼痛感、生活习惯严重不适。
- **社交表现**：回避熟人，说话语气僵硬，被搭话时慌乱，下意识用男声回答。
- **典型剧情点**：照镜子崩溃、尝试各种方法变回去、出门买生活用品的社死现场。

#### 阶段二：抗拒与挣扎期（第 4–15 章）

- **心理活动**：愤怒 → 不甘 → 焦虑，寻找变回去的方法，抵触女性身份，排斥女性化事物。
- **行为习惯**：
  - 刻意模仿男性行为，故意粗声说话、走中性风，拒绝穿裙子 / 化妆品；
  - 旧惯性逐渐碰壁：打架打不过、体力不支、被当成女生保护 / 骚扰；
  - 开始无意识出现小动作：拢头发、捂领口、小步走。
- **生理反应**：逐步适应基础生活，但生理期、体力上限等问题持续带来挫败感。
- **社交表现**：对男性的靠近保持警惕，排斥男性示好与保护欲，和女性相处不自在。
- **典型剧情点**：遭遇骚扰反被压制、第一次被当成女生对待、尝试用男性方式解决问题失败。

#### 阶段三：妥协与适应期（第 16–50 章）

- **心理活动**：接受短期无法变回去的现实，开始务实应对，身份认同进入模糊地带。
- **行为习惯**：
  - 主动调整行为模式：学习女性社交方式、注意言行举止、适应女性生活规则；
  - 旧习惯残留减少，但关键时刻仍会暴露（比如生气时的语气、遇危险的第一反应）；
  - 开始使用女性身份的便利解决问题，不再完全排斥。
- **生理反应**：完全适应日常生活，对身体的掌控力提升，开始利用身体优势。
- **社交表现**：建立新的社交圈，能自然应对两种性别的互动，有了稳定的女性身份人设。
- **典型剧情点**：利用女性身份破局、交到女性朋友、被人追求时的内心挣扎。

#### 阶段四：接纳与重构期（第 51–150 章）

- **心理活动**：接纳新的性别身份，建立新的自我认知，不再纠结「变回去」。
- **行为习惯**：
  - 行为举止自然流畅，不再刻意模仿或抗拒，形成融合式的独特风格；
  - 保留核心行事逻辑（比如原本理性务实，依然理性务实），只是表达方式更柔和；
  - 能自由切换不同状态应对不同场景。
- **生理反应**：完全掌控身体，能发挥身体优势，规避劣势。
- **社交表现**：社会身份稳定，周围人完全接受，能自如处理情感、职场、亲情关系。
- **典型剧情点**：身份公开后的坦然、主动以女性身份解决核心事件、做出符合新身份的重大决策。

#### 阶段五：整合与升华期（中后期至结局）

- **心理活动**：性别身份完全整合，不再是「男人在女人身体里」，而是「拥有男性思维的独立女性」。
- **行为习惯**：两种性别优势融合，形成独一无二的人格魅力与行事风格。
- **核心表现**：性别转变成为人物成长的一部分，而非束缚；最终结局无论是否变回去，人格都已完成升华。

### 模板 2：男转女 · 渐变式（女装大佬 / 缓慢变性）转变模板

#### 阶段一：试探与羞耻期

- 核心：初次接触女性着装 / 身体出现细微变化，强烈的羞耻感与好奇心并存。
- 行为：动作僵硬、刻意遮遮掩掩、怕被人发现，私下反复确认变化。
- 心理：自我说服「只是临时的」「都是为了任务」，强烈的身份焦虑。

#### 阶段二：习惯与动摇期

- 核心：常态化女装 / 身体变化明显，开始适应，身份认同出现动摇。
- 行为：动作逐渐自然，不再刻意遮掩，开始注意形象，无意识出现女性小动作。
- 心理：从「被迫」到「有点习惯」，开始怀疑自己的身份定位，出现认知混乱。

#### 阶段三：分化与选择期

- 核心：面临身份抉择，是退回男性身份，还是继续向前。
- 分支 1 坚守男性身份：女装只是工具，核心认同不变，形成「男装大佬 + 女装形态」双模式。
- 分支 2 偏向女性身份：逐步接纳，开始主动选择女性化的生活方式。
- 分支 3 混沌状态：不刻意选择，形成中性化行事风格，随环境切换。

### 模板 3：变嫁文 · 双重转变专属模板

在「男转女五阶段」基础上，新增 **情感与婚姻身份转变三阶段**，必须在「适应期」之后开启，禁止提前：

#### 情感阶段一：排斥与戒备

- 对所有男性保持距离，排斥肢体接触，对男性示好感到反感与荒谬。
- 内心坚持「我是男人，不可能喜欢男人」，对男主的接近保持警惕。
- 典型剧情：男主帮忙被冷眼相对、被表白时内心震怒。

#### 情感阶段二：改观与动摇

- 特定事件后对男主改观，发现对方的闪光点，从戒备到放松。
- 开始产生依赖感，遇到事情会下意识想到对方，自己都觉得荒谬。
- 内心反复拉扯：理智上抗拒，情感上动摇，自我怀疑性取向。
- 典型剧情：生病被照顾、遇险被救、共同经历难关。

#### 情感阶段三：接纳与身份重构

- 接受对男主的感情，完成性取向的自我认同。
- 从「被追求」转向「双向奔赴」，开始学习以女性身份表达情感。
- 婚姻身份转变：从「嫁人是耻辱」到「愿意和他共度一生」，完成妻子身份的心理重构。
- 典型剧情：主动示好、订婚 / 结婚前的内心独白、婚后角色适应。

### 模板 4：女转男 · 硬性转 转变模板（女频向）

  - 对新身体充满好奇，反复确认力量、身高、声音变化；
  - 刻意收敛女性化小动作，怕被发现异常。
- **生理**：体力暴涨、精力旺盛、声音变粗、生活习惯大幅改变。
- **社交**：不适应男性社交的直接与竞争感，对女性的靠近感到不自在。

#### 阶段二：探索与碰壁期

- **心理**：新鲜感过后的迷茫，体验男性世界的规则与特权，同时感受到压力与责任。
- **行为**：
  - 尝试男性的行为方式：直来直去、主动争取、用力量解决问题；
  - 旧习惯时常暴露：心思细腻、共情力强、情绪敏感，被吐槽「不像男人」；
  - 开始有意识地隐藏女性特质，模仿男性思维。
- **社交**：打入男性社交圈，体验兄弟情，同时感受到男性间的竞争与敌意。

#### 阶段三：适应与整合期

- **心理**：接纳新身份，建立新的自我认知，不再刻意模仿「纯爷们」。
- **行为**：
  - 保留原有的细腻、共情等特质，融合男性的果决与力量感；
  - 形成独特的行事风格，既有男性的魄力又有女性的细致。
- **社交**：自如应对两性社交，身份稳定，不再被质疑。

#### 阶段四：升华期

- 性别转变成为成长的助力，以新的身份实现自我价值。
- 结局无论是否变回，人格都已完成重构，不再受性别束缚。

### 模板 5：强制型性转（系统 / 诅咒 / 任务）特殊模板

适用于系统文、无限流、诅咒类等非自愿强制转变场景，在通用五阶段基础上新增三个核心特征：

1. **外部压力主导**：转变节奏由外部规则决定，人物被动应对，抗拒期更长，妥协更快；
2. **任务与转变绑定**：转变程度与任务完成度挂钩，有明确的奖惩机制；
3. **身份割裂感**：现实 / 任务外保持原性别，任务内转变，形成双重身份割裂感，心理压力更大。
- **核心崩盘点**：系统强制下人物完全没有心理挣扎，坦然接受；转变没有代价与惩罚。

### 模板 6：核心人设保留校验模板（通用）

用于审查性别转变后是否 OOC，以下核心特质不受性别影响，必须全程保留：

- **智商与思维模式**：理性 / 感性、激进 / 沉稳、心机重 / 直率；
- **行事原则**：底线、善恶观、做事风格（快准狠 / 稳妥 / 拖延）；
- **核心诉求**：复仇、变强、守护家人、搞事业等核心目标；
- **底层性格**：坚韧、懦弱、善良、腹黑、傲娇等底色特质。
- **崩盘点预警**：性别转变后智商下线、原则放弃、性格 180 度反转。

3. **输出规范（v3.3.1 统一附录式兼容）**：
   - **未命中性转题材时，输出与原来完全一致**，不输出任何额外内容；
   - 命中性转题材时：原有【整体评分 / 核心问题 / 优化建议 / 剧情风险预警】结构保持不动，在报告末尾统一追加**【专项审查附录】**（仅命中时显示），下含四子段：
     - 【转变节奏评分】：阶段完整性、节奏合理性（10 分制，列跳步 / 缺失 / 忽快忽慢失分项）；
     - 【心理逻辑评分】：身份认同、情绪转变合理性（10 分制，列秒接受 / 三观割裂失分项）；
     - 【行为细节评分】：习惯残留、转变细节真实度（10 分制，列秒适应 / 双状态割裂失分项）；
     - 【核心人设一致性校验】：逐项对照模板 6 核对是否 OOC；
   - 评分算法复用原有 12 维算法基础，**专项维度单独计分，不影响总分基准**；本专项默认**建议级**（仅输出提示 / 优化方向），运行稳定后可升级为**问题级**并纳入核心评分；
4. **反套路豁免**：作者明确声明的反套路设计（如「故意秒接受是伏笔」「强制型设定」「人格互换类」等）不判问题，改为提示「该设计需要在 X 节点前铺垫到位」；

## 五、冲突处理与优先级（v3.3.1 新增）

本规则为 gender-transition-rules 专项审查**子插件**，与九大核心通用规则冲突时严格遵循以下三原则：

1. **独立判定原则**：通用规则（AI 味 / 对话 / 人物 / 模板 / 合规等）与专项规则覆盖范围无交集时，各自独立判定、互不影响；
2. **通用优先原则**：判定维度重叠（如人物 OOC、行为逻辑穿帮、剧情节奏拖沓）时，**通用规则优先级高于专项规则**，以通用规则结论为准；
3. **不重复原则**：通用规则已判定为「问题」的内容，专项规则**不再重复判定**、不再重复扣分与重复建议，避免报告冗余与冲突。

以上三条与 INDEX.md 第 6 条仲裁顺序保持一致。

## 七、跨模块联动细则（v3.3.1 新增）

### 7.1 与大纲审联动（阶段规划校验三要点）

审大纲 / 卷纲 / 章纲 / 设定集时，本规则自动追加「大纲 × 性转阶段规划校验」：

1. 检查转变五阶段（冲击 → 抗拒 → 适应 → 接纳 → 整合）**是否在大纲中有明确节点**，防止漏阶段或跳步；
2. 检查**变嫁情感线与主线剧情的节奏匹配度**：情感线必须在「适应期」之后开启，禁止顺序颠倒（性别未接纳就进入恋爱）；
3. 检查**中期、后期的身份转变伏笔**是否合理：暴露 → 被发现 → 重构三节点的位置、代价、连锁反应是否清晰，避免中后期完全不提性别转变影响。

完全复用大纲审的「基础识别 → 模板匹配 → 专项审查 → 分层输出」流程，仅追加以上三个校验维度。

### 7.2 与系统文审查联动（系统 + 性转双源分流 + 交叉校验）

遇到「系统 + 性转」组合题材时，并行加载 system-novel-rules 与本规则，交叉校验：

1. 系统强制转变的**触发逻辑、奖惩机制、任务节奏、数值面板、登场时机**——走 system-novel-rules 四大维度与 20 类赛道模板；
2. 人物的**心理 / 行为 / 生理 / 社会身份转变过程**——走本规则六大维度与 6 套过程模板；
3. **双重校验一句话结论**：输出「系统任务节奏与人物转变节奏匹配度：高 / 中 / 低 + 失配节点」，低匹配度自动列为前瞻风险（如系统任务 3 章就要求完婚，但人物仍处于「抗拒期」）。

两套模板并行运行、各自输出对应维度结论，最终统一汇总到同一份报告；低优先级专项不覆盖高优先级判定。

### 7.3 与合规审查联动（复用 C1-C6 + 不独立合规定论）

1. **完全复用**原有平台合规红线 C1-C6（政治 / 色情 / 暴力 / 迷信 / 价值观 / 平台）与 G1-G6 门禁清单；
2. 性转题材专属风险点**补充说明**（不改动通用合规标准）：过度露骨的生理描写、未成年人涉性、福利化性暗示、价值导向问题、低俗擦边、性别刻板化煽动；
3. 合规判定仍由**合规模块统一输出**，本规则仅向合规模块提供性转专属风险点，不单独出具合规定论、不单独给出发布/暂缓结论。
