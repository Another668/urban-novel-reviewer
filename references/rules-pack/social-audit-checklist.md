# 人情世故审计清单
本章内容需全部通过以下校验，不合格需标注并修改。

## 人物行为逻辑
- [ ] 所有人物决策符合自身利益与立场，无强行降智
- [ ] 人物行为匹配其社交段位与身份地位
- [ ] 没有出现不符合人设的直白发言或情绪爆发

## 对话质量
- [ ] 核心对话存在表层语义与深层潜台词分层
- [ ] 不同人物说话风格有明显区分，不千人一面
- [ ] 对话中有适当的停顿、犹豫、改口、打断，非全程工整

## 人情往来逻辑
- [ ] 求人、帮忙、欠人情、还人情逻辑自洽
- [ ] 人情轻重匹配事件等级，不小题大做
- [ ] 没有无缘无故的善意或恶意，所有立场皆有原因

## 社交规矩
- [ ] 符合对应场景的身份尊卑、长幼有序规则
- [ ] 当众与私下的人物态度差异合理
- [ ] 高位者保持了相应的城府与体面

## 活人感细节
- [ ] 情绪有对应的微动作/神态描写
- [ ] 人物有不完美的小习惯或反应
- [ ] 情绪反应有延迟或掩饰，不是当场全部爆发
