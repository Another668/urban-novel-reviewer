# 对话博弈与真人化审查规则包（Dialogue Game Rules Pack）

> 整合来源：网文对话博弈大师（5 铁则/3 场景公式/话题阶梯/14 范例）、novel-social-intelligence-skill（对话分层/活人感）、oh-story story-review dialogue-mastery（权力博弈量化/对话三症状）、novel-audit（对话 DNA/弦外之音 30%）、番茄 dialogue-monitor（对话占比）。
> 适用维度：C4 对话质量（主）、D1 人情世故（辅）、A3（对话层 AI 味联动）。
> 加载时机：全审必载；"只查对话/智斗/谈判"指定维度审主载。

## 一、形式审查（量化阈值，可机检）

| 编号 | 规则 | 阈值 | 判罚 |
|---|---|---|---|
| F1 | 对话-动作锚定 | 每 2-3 句对白 ≥1 处动作/神态/环境/心理锚定；**连续 ≥4 个对白轮次无任何锚定 = 飘对话** | 🔴 长段飘对话；🟡 局部 |
| F2 | 单段对白容量 | 每段 ≤3 句对白；**单条台词 >50 字且其后 1 轮内无对方反应 = 独白演讲** | 🟡 |
| F3 | 提示语变化 | 提示语位置前/中/后交替；禁止全"XX 说"开头；禁止"生气地说/开心地说/愤怒地吼"直白情绪副词（正则：`(生气\|开心\|愤怒\|冷笑\|高兴)地?[说道吼骂]`） | 🟡 |
| F4 | 对话占比 | 行数法：含引号行数/非空总行数；字数法辅证。≤25% 优秀 / 26-35% 良好 / 36-40% 偏高 / 41-50% 超标🔴 / >50% 严重🔴。分章型上限：战斗 30%/悬疑 25%/探索 35%/过渡 40%/对话章 45%（任何情况 ≤50%）；开篇前 10 章 ≤25%。连续 3 章上升预警 | 门禁项 |
| F5 | 潜台词占比 | 重要对白 = 表层义 + 真实意图 + 情绪暗流三层；直白说明 ≤30%，≥70% 藏语气/动作/话外音；全章至少 30% 对白含弦外之音 | 🟡 |
| F6 | 千人一面 | 去掉说话人名字无法区分谁在说话；同台两人语言指纹相似度 >0.7（向量库比对）；口癖/句长/用词层级无差异 | 🔴 |
| F7 | 信息倾倒 | 台词纯复述剧情/设定原理；角色当"科普嘴"整段讲设定；单人连续 >3 句且每句传新信息无动作隔开 | 🟡/🔴 |

## 二、博弈结构审查（智斗/谈判/对峙场景专项，本包新增能力）

### 2.1 轮次推进（所有对话场景）

- **每轮必须改变局势**，四选一：抛新信息 / 亮筹码 / 突破防线 / 转移话题。
- **局势零变化**：对话结束时双方关系/信息/筹码状态与开场相同，plots 无对应 event → 🟡 无效对话。
- **轮次空转**：连续 >2 轮无新 slots 实体、无新信息，同义反复 → 🟡 原地拉扯。

### 2.2 话题阶梯升级法（防卡壳公式）

每 3 轮对话上一个台阶；**同一阶停留 >2 轮无进展必须抛新变量**（新信息/新筹码/意外打断）：

| 阶位 | 层面 | 话题 |
|---|---|---|
| 一阶 | 事实 | 聊表面事件 |
| 二阶 | 立场 | 聊动机与态度 |
| 三阶 | 底线 | 聊身份与原则 |
| 四阶 | 利益 | 聊后果与代价 |

### 2.3 场景公式

**场景 A 对峙/辩论/嘴遁（攻防回合制）**：
- 攻击方动作库：揭短 / 抛证据 / 逻辑归谬 / 情感绑架 / 道德施压；
- 防守方动作库：否认 / 辩解 / 转移矛头 / 倒打一耙 / 沉默冷处理；
- 转折回合：一方抛关键信息/打破对方逻辑/戳中软肋 → 局势反转；
- 节奏：克制试探 → 针锋相对 → 破防爆发，逐级加速；
- **强制平衡**：禁止一方全程碾压，弱势方 ≥1-2 次有效反击或转移，否则 🟡；
- 高压/生死 beat 禁止插科打诨（说话不分场合 = 🟡/🔴）。

**场景 B 谈判/交易/商战（筹码拉锯线）**：
六步推进：试探 → 出价 → 还价 → 威胁（亮底牌/时间限制/替代方案）→ 让步 → 成交/破裂。
- 每轮条件必须有变化；禁止一口价当场成交；
- 表面客气、句句带刀，利益交换藏客套话下；停顿/斟酌/眼神/肢体小动作体现心理博弈；
- **反派双层**：明面共识 + 真实目的；承诺留后路、话术藏陷阱；结盟期互瞒底牌只抛共同利益；**背刺前必有试探铺垫，禁止突然翻脸**（无 leverage 记录的翻脸 = 🔴）。

**场景 C 宅斗/宫斗/豪门**：攻击裹"为你好/守规矩"外壳；捧杀、挑错、递把柄、借规矩压人；不直白骂街；输赢留体面；商战/豪门禁止过度口语化失精英感。

**场景 D 日常/人情/暧昧**：
- 对话推进信息或关系，禁止无信息寒暄凑字数；生活化打断、抢话、话说一半、转话题；
- 暧昧禁止直白抒情，情绪靠动作/语气/潜台词；
- 求人/拒绝/随礼四段逻辑：**客套铺垫 → 说事 → 推拉 → 收尾**；话不说透、留台阶；拒绝不撕破脸，求人不卑不亢。

### 2.4 权力博弈量化（story-review）

- 掌控者台词 ≤10 字、不加动作；被压制方 ≥20 字、可加动作（反过来写 = 权力感失真）；
- 单次对话不超全节 40%；
- 冲突对话五级递进：客观陈述 → 陈述+建议 → 主观指责 → 指责+命令 → 指责+PUA（越级跳变需情绪触发）。

## 三、真人化（活人感）检查

- [ ] 对话非全程工整：有停顿、犹豫、改口、打断、答非所问、重复对方话、无意义语气词
- [ ] 情绪有对应微动作/神态，而非副词标签
- [ ] 人物有不完美的小习惯或口癖
- [ ] 情绪反应有延迟或掩饰（城府型角色不当场爆发）
- [ ] 对话 DNA 五维有个体差异：句式偏好（长短/反问）、词汇层级（文言/白话/网语/行业词）、语气词习惯（呢吧啊嘛）、情感表达（直说/暗示/反话/沉默）、口头禅（1-2 个独特小词）
- [ ] 身份口吻匹配：古代文人不甩网语、农村老农不说文绉绉长句、反派大佬短句多命令少解释
