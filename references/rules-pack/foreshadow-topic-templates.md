# 分题材伏笔模板库（v3.4.0 新增）

v3.4.0 新增。伏笔追踪专项的**分题材模板**，为每个主流 / 小众题材配套对应的伏笔模式模板。**挂载机制**：完全复用现有题材模板匹配机制（genre-classifier → templates/ 加载），加载主题材模板时自动挂载本库对应小节——**模板叠加顺序：主题材模板 → 系统模板（如有）→ 性转插件模板（如有）→ 伏笔分题材模板**，各模板负责各自维度互不冲突，基础标准永远以主题材模板为准。

**价值**：不同题材采用不同的伏笔合理性标准，避免一刀切误判（都市文不需要玄幻级的体系伏笔密度；系统文的任务伏笔节奏与悬疑文的谜底伏笔节奏完全不同）。

## 二、专项题材模板细则

### 1. 系统文（联动 system-novel-rules）

- **任务伏笔**：任务描述中的措辞异常（措辞含糊、限定条件反常）→ 后续任务反转 / 隐藏任务揭示；系统文标配，埋设密度高但回收快；
- **奖励伏笔**：奖励列表中「??？」未知项、被锁定的奖励格子 → 兑现时应与任务线匹配；**校验**：隐藏奖励解锁时是否与此前任务措辞呼应（无呼应 = 空降奖励，判 C3）；
- **系统升级伏笔**：系统版本号 / 升级条件 / 系统沉默节点（系统突然不说话）→ 系统来源之谜的中长线伏笔；
- **专属校验清单**：① 系统任务的措辞性伏笔与后续揭示是否一致（前后任务文案对照）；② 奖励未解锁项是否全部有兑现计划（台账膨胀高发区）；③ 系统来源 / 真相类大结局伏笔是否每 30-50 章有强化（沉默节点、异常播报）；
- **与系统文专项联动**：伏笔校验发现任务 / 奖励前后不一致时，同时触发 system-novel-rules 机制校验（任务节奏 / 奖励梯度），双专项结论分别输出、问题统一汇总。

### 2. 性转 / 变嫁（联动 gender-transition-rules）

- **身份伏笔**：转变前后的身体特征残留、旧身份的人际联系（旧友认出、旧习惯暴露）→ 身份暴露节点的铺垫链；**校验**：暴露节点前是否有 ≥3 处强化（暴露 → 被发现 → 重构三节点前置铺垫，与性转阶段规划校验三要点衔接）；
- **情感伏笔**：CP 方的异常容忍、提前知情的暗示（眼神、台词）→ 是否「早就知道」的揭示；
- **秘密伏笔**：知情第三人（闺蜜 / 室友 / 医生）的沉默 → 后期倒戈或助攻的伏笔；
- **转变原因伏笔**：变身触发源（诅咒源 / 系统目的 / 药物来源）→ 大结局级，需每 30-50 章强化；
- **专属校验清单**：① 身份暴露三节点（暴露→被发现→重构）的铺垫完整性；② 情感线开启（适应期后）前的情感伏笔密度是否足够（变嫁文铺垫不足 = 性转专项判 C4，本专项补充台账证据）；③ 转变原因大结局伏笔是否启动回收；
- **与性转专项联动**：伏笔台账为性转专项的「铺垫够不够」判定提供量化证据（强化章分布）；两专项结论分别输出。

### 3. 末世 / 玄幻（联动高武 / 异能 / 仙侠模板）

- **战力伏笔**：主角能力的隐藏上限、变异 / 觉醒的前置征兆（F12-F14）→ 阶段性兑现；
- **势力伏笔**：多方布局（F18）——避难所派系 / 宗门势力的暗中角力，各方手牌必须有完整揭示计划（某方蒸发 = 遗忘预警高发区）；
- **物品伏笔**：末世 = 物资 / 病毒样本；玄幻 = 功法残页 / 法宝认主（F1）；
- **崩盘点**：势力伏笔半途蒸发（作者写到中后期忘了某派系）；体系伏笔吃书（前期设定的一阶一阶，后期直接跳）；
- **校验清单**：① 势力方手牌台账是否全部有回收计划；② 力量体系层级伏笔（F14）是否每 30 章强化；③ 功法 / 物品的「来历不明 → 揭示」链是否完整。

### 4. 商战 / 职场（联动都市商战矩阵 genre-matrix）

- **人脉伏笔**：早期帮助过的小人物后期的关键回报（F11 关系暗线）；**校验**：回报时是否呼应早期帮助（无呼应 = 空降救兵，判 B1 上帝之手——本专项只补台账证据）；
- **信息差伏笔**：主角知道而对手不知道的信息（F3 文件 / F4 影像）→ 布局收官时的关键筹码；
- **布局伏笔**：多方资本暗流（F18）——每方布局需有揭示计划；
- **崩盘点**：信息差凭空出现（埋设缺失）；人脉回报无前期铺垫；
- **校验清单**：① 每次关键筹码使用前是否有 ≥1 处埋设记录；② 布局类伏笔的回收是否集中于收官章（密度 ≤3 条/章）。

### 5. 悬疑 / 推理（高密度题材专属标准）

- **多层真相**：三层递进（表层真相 → 深层真相 → 核心真相），每层回收时需留下指向下层的钩子（回收即埋设，链式结构）；
- **不可靠信息**：叙述者 / 证人的表述偏差（F4 影像矛盾、F5 痕迹与自述不符）→ 翻转节点；
- **时间诡计**（F6）：叙事时间与事件时间的错位 → 终局揭示；
- **专属标准**：悬疑文埋设密度为全题材最高（每章 ≥2），但**回收必须完整**——终局章 open 伏笔 = 🔴 硬伤（其他题材为 🟡）；
- **校验清单**：① 三层真相的链式钩子是否完整；② 终局前所有中等以上优先级伏笔是否全部 closed；③ 翻转节点前的不可靠信息埋设是否 ≥2 处。

## 三、跨题材通用雷区（判罚与题材无关）

1. **空降伏笔**：回收时才「补埋」（回收内容此前无任何埋设记录）→ 判 B1 因果断裂（通用规则优先，本专项登记台账证据）；
2. **伏笔坟场**：高开低走的长线伏笔群（开局密集埋设、中后期集体蒸发）→ 台账膨胀 + 遗忘双重预警；
3. **回收倾销**：结局章一次性回收 >5 条 → 信息倾倒，判 C1；
4. **伪伏笔**：描写故弄玄虚但无回收计划（作者自己也忘了为什么写）→ 标记待验证，提示作者确认是否为水字数（判 A1）；
5. **重复埋设**：同一钩子反复以「新信息」面貌出现但无增量 → 冗余强化，🟢 提示合并台账条目。

## 四、大纲审联动（大纲 × 伏笔）

大纲 / 卷纲 / 章纲审稿时（第三章大纲分支），伏笔专项自动叠加以下校验：

1. **伏笔节点规划校验**：大纲中是否明确标注了伏笔的埋设点与回收点（章纲级）；只有埋没回收 = 🟡 回收计划缺失，提示补规划；
2. **回收节奏校验**：大纲规划的回收间距是否符合本库题材节奏表（速查表「主导回收节奏」列）；
3. **长线布局合理性**：跨卷长线伏笔在大纲中是否有中途强化节点（每 20-30 章）；
4. **伏笔负载评估**：按大纲推算全书 open 伏笔峰值是否 > 20 条（膨胀预警前置到大纲阶段）；
5. **只提建议铁则**：对大纲只输出规划诊断与节奏建议，不改写大纲、不代写伏笔剧情。

## 五、模板叠加与冲突处理

- **叠加顺序**：主题材模板 → 系统模板（如有）→ 性转插件模板（如有）→ 伏笔分题材模板；主题材模板的基础标准（叙事节奏 / 爽点密度）永远优先，伏笔模板只负责伏笔维度的密度与节奏标准；
- **冲突处理三原则**：① 通用与专项无交集时各自独立判定；② 判定重叠时「通用规则优先级高于专项规则」；③ 通用规则已判定为「问题」的内容，本模板不重复判定（避免双重扣分）；
- **混合题材**：按主辅题材分别取对应小节的标准，密度取主线要求、节奏取主题材节奏。
