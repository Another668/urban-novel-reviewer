# 系统文专项审查规则与全类型模板库（System Novel Rules）

v3.2.0 新增、v3.2.1 扩充（12 类细分/小众赛道模板 + 12 套系统性格人设模板 + 双校验/前瞻推演/输出模块）。系统文（含系统/面板/任务奖励/签到/商城/属性加点等金手指机制）专项规则。**两个加载入口**：
- **大纲审**：设定集 / 大纲含系统要素时必载，做前瞻性审查（主入口）；
- **正文审**：已写章节中系统相关内容出问题时加载，按 SKILL.md 六步工作流第 4 步联动 C2 人物塑造 / C3 世界观自洽 / D2 连载一致性（数值穿帮、任务伏笔账）。

核心思想：**前瞻性校验**——在设定/大纲阶段提前规避后期剧情崩盘、数值膨胀、主角工具人化。

---

## 一、四大审查维度

### 维度 1：系统出现时机

| 审查项 | 合理标准 | 前瞻风险（不达标） |
|--------|---------|------------------|
| 登场节点 | 黄金三章内（第 1-3 章）；先抑后扬型最多延后至第 5 章，**上限不超过第 10 章** | 登场过晚 → 开篇无钩子留不住读者；登场过早 → 缺主角原生性格铺垫，后期易工具人化 |
| 触发逻辑 | 必须有明确触发点（绝境 / 死亡 / 穿越 / 执念 / 信物 / 血脉觉醒），**禁止凭空出现** | 无逻辑触发 → 设定悬浮、代入感差，后期易出现系统万能化 |
| 初始信息 | 首次登场只交代基础功能与核心规则，**禁止一次性放出全部设定** | 初始信息过多 → 信息轰炸，后期无解锁新鲜感，容易提前写崩 |

### 维度 2：任务发布机制

| 审查项 | 合理标准 | 前瞻风险（不达标） |
|--------|---------|------------------|
| 任务层级 | 三级梯度清晰：①**主线任务**绑定剧情大节点、推动核心成长；②**支线任务**填充过渡、补全人物/世界观；③**日常任务**调节节奏、小额奖励 | 层级混乱 → 主线模糊、剧情碎片化，后期变成无限做任务的工具人文 |
| 发布节奏 | 主线任务间隔 **≥10 章**；支线任务每 **3-5 章** 1 个；日常任务每日/每周固定频次 | 任务过密 → 主角失去主观能动性，完全被系统牵着走，人物弧光消失 |
| 强制度 | 可选任务占比 **≥60%**，强制任务仅用于关键剧情转折点 | 强制任务过多 → 主角工具人化、读者代入感崩塌，后期无法安排自由剧情 |
| 任务逻辑 | 任务内容必须贴合主角身份与当前剧情阶段，**禁止跨阶段发布任务** | 任务与主线脱节 → 剧情割裂，后期世界观扩大后系统任务完全失效 |

### 维度 3：奖励体系合理性

**核心原则：梯度递增、匹配难度、限制明确。**

| 审查项 | 合理标准 | 前瞻风险（不达标） |
|--------|---------|------------------|
| 强度梯度 | 前期偏功能性（技能、启动资金、基础属性），中期偏成长性（天赋、装备、权限），后期偏核心级（规则级、世界观级） | 前期奖励过强 → 开局无敌、后续无冲突，中期直接数值膨胀崩盘 |
| 难度匹配 | 奖励强度与任务难度严格正相关；日常任务奖励不影响世界观平衡 | 奖励与难度脱节 → 系统失去公信力，后期高难度任务失去吸引力 |
| 限制机制 | 所有奖励必须有明确约束：使用场景限制 / 冷却时间 / 解锁条件 / 副作用 | 奖励无限制 → 系统万能化，主角失去成长意义，所有冲突都能靠系统解决 |
| 数值管控 | 建立明确的数值膨胀曲线；**前期奖励数值不超过当前世界观上限的 10%** | 无管控 → 中期数值崩盘、战力体系崩溃，后期只能不断加设定圆谎 |

### 维度 4：系统本身设定

| 审查项 | 合理标准 | 前瞻风险（不达标） |
|--------|---------|------------------|
| 存在感 | 工具属性明确，仅发布任务 + 结算奖励，**禁止过度人格化抢主角戏份** | 人格化过重 → 变双主角、读者代入感下降，后期容易写成系统和主角谈恋爱 |
| 升级逻辑 | 系统本身有明确升级/解锁路径，与主角成长同步推进 | 一成不变 → 后期功能跟不上剧情，只能强行加新功能，设定越补越乱 |
| 终极目标 | 系统存在最终目的（集齐信物 / 回归本源 / 达成执念 / 重构世界等），**不能无限发布任务** | 无终极目标 → 剧情无限拖曳，后期强行完结，大概率烂尾 |
| 信息差 | 系统与主角存在信息差，核心真相逐步解锁 | 全知全能 → 剧情无悬念，后期没有反转空间 |
| 人设一致性（v3.2.1） | 系统人格（语气/行为/边界/句式）与其所属性格模板（第三章）全程一致，一经定型不得中途突变；对应性格模板的"崩盘点预警"项（抢戏/剧透/保姆包办/话痨破坏悬疑等）不得集中触发 | 系统 OOC 突变 → 读者出戏、人设崩塌；崩盘点集中触发 → 系统变双主角、主线失焦或悬疑感被破坏 |
| 题材适配度（v3.2.1） | 系统类型与赛道模板匹配，且与题材/整体文风自洽（诡异克苏鲁不宜配软萌话痨型、硬核科幻不宜配毒舌玩梗型）；跨题材反差人设须有明确反差设计铺垫 | 类型-题材违和 → 文风撕裂；系统性格与赛道机制互斥（如反派掠夺机制配软萌放水人设）→ 机制与人设互相打架 |

## 二、系统文全类型标准模板库（审稿对标用）

v3.2 内建 8 大主流系统类型，v3.2.1 扩充 12 类细分 / 小众赛道，共 **20 类**。命中对应类型时按其"设定标准"对标、按"崩盘点"排查、按"审稿校验清单"逐项过；命中类型再按其适配性格模板交叉做人设一致性校验（见第三章）。

### 2.1 主流系统类型（v3.2 内建 8 类）

#### 1. 签到流

- **核心定义**：固定时间/地点签到获取奖励，弱任务导向，主打轻松稳定爽感。
- **合理设定标准**：
  1. 签到地点随主线剧情逐步解锁，新地点对应新奖励池；
  2. 奖励梯度：日常签到→小额实用；周/月签到→稀有道具；关键节点签到→核心奖励；
  3. 前期日常奖励不破坏世界观平衡（都市文日常签到不超过 10 万元）；
  4. 保底 + 暴击机制，避免长期非酋导致读者流失。
- **常见崩盘点**：开局签到神级天赋直接无敌；奖励无节制数值膨胀；签到地点与剧情脱节。
- **校验清单**：签到冷却是否明确？地点解锁和主线进度是否匹配？奖励梯度是否清晰？顶级奖励有无获取限制？

#### 2. 神豪流

- **核心定义**：以金钱消费为核心机制，任务绑定消费行为，主打花钱爽感。
- **合理设定标准**：
  1. 初始启动金符合世界观层级（都市文开局 10 万-100 万），逐级递增；
  2. 消费任务有明确场景限制，禁止直接给现金，必须通过消费/投资转化；
  3. 花钱与收益绑定，不能只出不进，后期要有实业/资本布局承接资金；
  4. 系统资金有明确来源设定（未来账户/外星科技/位面交易等），不能凭空造钱。
- **常见崩盘点**：开局直接给百亿千亿，数值瞬间崩盘；花钱无逻辑、脱离现实；后期钱太多失去意义。
- **校验清单**：初始资金是否合理？消费限制是否明确？资金增长节奏是否匹配剧情？后期有无承接资金的实体产业？

#### 3. 职业 / 技能流

- **核心定义**：绑定特定职业，通过完成职业行为升级解锁技能，主打成长感。
- **合理设定标准**：
  1. 职业与主角身份强绑定，技能完全服务于职业场景；
  2. 技能分级清晰（初级→中级→高级→大师→宗师→神级），升级难度指数级上升；
  3. 前期技能偏基础操作，中期偏行业核心能力，后期偏行业规则级影响；
  4. 技能效果写实，不超出现有职业的能力边界（除非有异能设定铺垫）。
- **常见崩盘点**：技能跨职业超纲；神级技能出现过早；职业成长与剧情主线脱节。
- **校验清单**：职业与主角人设是否匹配？技能分级是否清晰？技能效果是否符合职业边界？升级节奏是否合理？

#### 4. 末世求生流

- **核心定义**：末世背景下的生存 + 升级系统，主打绝境求生与战力成长。
- **合理设定标准**：
  1. 初始奖励仅保障基础生存（食物、水、基础武器），禁止开局给重火力；
  2. 任务以生存、探索、收集、建基地为主，贴合末世世界观；
  3. 战力梯度与丧尸/变异兽等级严格对应，禁止越级秒杀；
  4. 系统功能逐步解锁：生存→战斗→建造→科技，匹配基地发展节奏。
- **常见崩盘点**：开局神装无敌；物资无限供应失去求生感；战力膨胀过快，末世变无双。
- **校验清单**：初始物资是否符合求生设定？战力体系是否对应？系统解锁节奏是否匹配基地发展？生存压力是否维持？

#### 5. 诸天穿梭流

- **核心定义**：穿梭不同世界完成任务，获取奖励带回主世界，主打多元世界观。
- **合理设定标准**：
  1. 穿梭世界难度递增，从低武到高武、从现代到玄幻；
  2. 世界停留时间有限制，任务完成强制回归，禁止长期滞留；
  3. 带回奖励有强度上限，高武世界的能力在主世界有削弱机制；
  4. 主世界剧情线不能断，穿梭间隔要有主世界过渡剧情。
- **常见崩盘点**：开局穿梭高武世界直接成神；主世界剧情被边缘化；能力无限制带回，主世界战力崩盘。
- **校验清单**：世界难度梯度是否清晰？停留时间是否有限制？带回奖励是否有削弱？主世界与副本世界节奏是否平衡？

#### 6. 种田经营流

- **核心定义**：绑定土地/店铺/领地，通过经营发展升级，主打慢热养成感。
- **合理设定标准**：
  1. 初始规模小（一亩地/小破店/小村庄），逐步扩大；
  2. 产出与投入成正比，有明确生产周期，禁止瞬间产出；
  3. 经营品类逐步解锁，高级品类需要特定条件（等级、图纸、材料）；
  4. 要有经营阻力（天灾、同行竞争、官府管理等），不能一帆风顺。
- **常见崩盘点**：开局产出爆炸瞬间暴富；经营无阻力全程平铺直叙；规模扩大后没有对应管理体系。
- **校验清单**：初始规模是否合理？生产周期是否明确？解锁条件是否清晰？有无经营冲突与阻力？

#### 7. 攻略 / 好感度流

- **核心定义**：通过与角色互动提升好感度获取奖励，主打情感线与人物塑造。
- **合理设定标准**：
  1. 好感度分级清晰（陌生→熟悉→好感→信任→挚友→生死），每级有明确行为边界；
  2. 好感度提升必须有对应事件支撑，禁止刷脸/送东西无脑涨；
  3. 每个可攻略角色有独立人设与喜好，不能千篇一律；
  4. 奖励以人脉、信息、专属技能为主，禁止直接给战力/金钱。
- **常见崩盘点**：好感度涨得莫名其妙；角色人设模板化；奖励破坏主线平衡。
- **校验清单**：好感度分级是否明确？提升是否有事件支撑？角色人设是否有差异？奖励是否符合情感线定位？

#### 8. 属性加点流

- **核心定义**：获取属性点自由分配，强化身体/技能/天赋，主打自由成长。
- **合理设定标准**：
  1. 属性分类清晰（力量、敏捷、体质、精神、魅力等），每项属性有明确效果；
  2. 属性点获取渠道唯一（任务/升级/成就），数量严格管控；
  3. 普通属性上限明确，超出常规上限需要特殊条件（天赋、血脉、功法）；
  4. 加点效果线性增长，前期收益明显，后期边际递减。
- **常见崩盘点**：属性点泛滥；单属性堆到极致直接无敌；属性效果模糊全靠作者嘴说。
- **校验清单**：属性分类与效果是否明确？属性点获取是否可控？数值上限是否清晰？边际递减是否体现？

### 2.2 细分 / 小众系统类型模板（v3.2.1 新增 12 类）

覆盖反派/直播/词条/养成/轮回/马甲/学霸/诡异/宗门/美食/军阀/赘婿等细分赛道，与 2.1 主流模板同一套"设定标准 / 崩盘点 / 校验清单"对标结构。

#### 9. 反派 / 掠夺系统

- **核心定义**：绑定反派身份，通过掠夺主角机缘、打压气运之子、篡改剧情节点获取奖励，主打反套路反差爽感。
- **合理设定标准**：
  1. 初始反派身份符合世界观层级，禁止开局就是最终 Boss 级；
  2. 掠夺目标与原剧情主角强相关，奖励强度与掠夺难度严格正相关；
  3. 保留原主角成长性，不能一次性废掉核心主角，否则后期失去冲突锚点；
  4. 有明确终极目标（取代气运、自保求生、颠覆世界等），禁止无限掠夺。
- **常见崩盘点**：主角过度弱化失去对抗性；掠夺无底线导致剧情崩盘；反派洗白生硬无铺垫。
- **审稿校验清单**：反派初始定位是否合理？掠夺机制是否匹配剧情？原主角是否保留成长空间？终极目标是否清晰？

#### 10. 直播 / 弹幕系统

- **核心定义**：绑定跨位面直播面板，通过观众情绪值、打赏获取奖励，主打互动感与整活爽感，覆盖都市、诸天、娱乐圈赛道。
- **合理设定标准**：
  1. 观众群体设定统一（同世界 / 跨位面），弹幕风格符合观众身份认知；
  2. 情绪值 / 打赏转化比例明确，前期收益不破坏世界观平衡；
  3. 直播内容有选择性，禁止全程无死角直播，保留主角隐私与底牌；
  4. 功能分级解锁：普通弹幕→打赏特效→跨位面沟通→现实干涉。
- **常见崩盘点**：弹幕抢戏盖过主线；打赏奖励爆炸直接无敌；观众全知全能剧透。
- **审稿校验清单**：观众群体设定是否统一？奖励转化比例是否可控？直播边界是否明确？弹幕是否影响主线叙事？

#### 11. 词条 / 设定编辑系统

- **核心定义**：通过修改人物 / 物品 / 事件的词条设定改变现实，主打脑洞与反转，属于高概念小众赛道。
- **合理设定标准**：
  1. 编辑次数 / 能量消耗严格管控，前期只能修改细微设定（如"字迹工整"）；
  2. 编辑范围有明确边界，禁止直接修改核心规则（如"全域无敌"）；
  3. 每次修改都有连锁反应与隐性代价，不能无成本改写现实；
  4. 词条等级分层：普通→稀有→史诗→传说，等级越高修改代价越大。
- **常见崩盘点**：前期直接改核心设定秒无敌；修改无代价逻辑崩盘；连锁反应无法自洽。
- **审稿校验清单**：编辑消耗与次数是否受限？修改范围是否有明确边界？是否有代价与连锁反应？词条等级是否清晰？

#### 12. 养崽 / 宿主养成系统

- **核心定义**：系统以"养成宿主"为核心目标，通过引导健康生活、学习、成长发放奖励，主打温馨治愈；或反向——宿主养成幼体系统。
- **合理设定标准**：
  1. 养成目标明确（体魄、学识、性格、实力等），分阶段里程碑；
  2. 任务贴近日常，符合宿主当前年龄段 / 身份，禁止跨阶段发布成人任务；
  3. 奖励以成长属性、日常物资为主，禁止直接给顶级战力 / 巨额财富；
  4. 系统存在感偏辅助，不强制干预决策，主打引导而非控制。
- **常见崩盘点**：任务脱离年龄设定；奖励超标破坏日常感；系统过度控制宿主。
- **审稿校验清单**：养成目标与阶段是否清晰？任务是否符合宿主身份？奖励是否匹配日常定位？系统边界是否明确？

#### 13. 轮回 / 死亡回档系统

- **核心定义**：宿主死亡后回档到指定时间点，保留记忆重新推进，通过试错解锁真相，主打悬疑与硬核解谜。
- **合理设定标准**：
  1. 回档有明确限制：次数上限、精神消耗、固定回档点，禁止无限回档；
  2. 每次回档保留记忆，但存在世界线偏移，不能完全复刻过往；
  3. 关键剧情节点有锁死机制，不能靠回档直接跳过核心冲突；
  4. 随剧情推进解锁更长回档跨度，开局仅支持短时间（小时级）回档。
- **常见崩盘点**：无限回档失去张力；回档无记忆代价主角秒变先知；关键剧情直接跳过。
- **审稿校验清单**：回档次数与消耗是否明确？回档跨度是否逐步解锁？是否有世界线变动代价？关键节点是否有锁死机制？

#### 14. 身份扮演 / 马甲系统

- **核心定义**：系统发布身份任务，宿主切换不同马甲完成目标，解锁对应能力，主打多重身份的爽感与反转。
- **合理设定标准**：
  1. 每个马甲有独立人设、能力、社交圈，禁止马甲之间能力通用；
  2. 马甲解锁节奏与主线匹配，前期 1-2 个基础马甲，中期逐步增加；
  3. 身份暴露有明确惩罚，马甲切换有冷却与场景限制；
  4. 本尊身份始终是主线核心，马甲服务于主线，不能反客为主。
- **常见崩盘点**：马甲过多叙事混乱；马甲能力超标盖过本尊；身份暴露无代价。
- **审稿校验清单**：每个马甲人设与能力是否独立？解锁节奏是否匹配主线？切换限制是否明确？本尊主线是否稳固？

#### 15. 学霸 / 知识转化系统

- **核心定义**：通过学习知识、完成学业、产出科研成果转化为属性、技能、现实收益，主打学习成长爽感，覆盖校园、科研、都市赛道。
- **合理设定标准**：
  1. 知识与奖励对应明确：学什么得什么，禁止学数学加武力；
  2. 学习有时间成本与认知门槛，不能秒懂秒会，符合学习规律；
  3. 奖励分级：课本知识→基础属性；专业知识→专属技能；科研成果→核心权限；
  4. 前期仅强化自身，后期才能转化为现实收益（专利、创业等）。
- **常见崩盘点**：过目不忘秒学一切；知识直接转化为战力脱离设定；前期直接科研突破不符合身份。
- **审稿校验清单**：知识与奖励是否对应？学习成本是否体现？奖励梯度是否清晰？是否符合当前身份的认知水平？

#### 16. 诡异 / 克苏鲁系统

- **核心定义**：绑定诡异力量，通过接触异常事件、解析污染物获得能力，伴随理智值消耗与失控风险，主打悬疑惊悚。
- **合理设定标准**：
  1. 力量与理智值（SAN）挂钩，能力越强理智消耗越大，有明确失控阈值；
  2. 诡异事件分级，低等级可处理，高等级只能规避，禁止开局硬刚顶级异常；
  3. 系统本身带有未知性，信息逐步解锁，禁止开局全知全能；
  4. 有明确的理智恢复途径，不能持续掉 SAN 无补给。
- **常见崩盘点**：理智值形同虚设；开局接触顶级诡异直接无敌；系统全知失去悬疑感。
- **审稿校验清单**：SAN 值机制是否明确？诡异事件分级是否清晰？系统信息是否逐步解锁？理智恢复途径是否存在？

#### 17. 宗门 / 门派建设系统

- **核心定义**：绑定残破宗门，通过招收弟子、建设山门、提升宗门等级获取奖励，主打修仙 / 玄幻类种田经营 + 成长。
- **合理设定标准**：
  1. 初始宗门残破（小破山、零星外门弟子），等级划分明确（九品→一品→仙门）；
  2. 建设资源有明确获取途径，不能凭空产出，弟子资质呈正态分布；
  3. 宗门发展与主角个人成长绑定，不能只建设不修炼，实力同步推进；
  4. 有宗门竞争、大比、围剿等外部冲突，不能全程和平发育。
- **常见崩盘点**：开局直接招天骄弟子；资源无限秒建仙门；主角实力跟不上宗门等级。
- **审稿校验清单**：初始宗门规模是否合理？资源获取途径是否明确？弟子资质是否有梯度？主角与宗门成长是否同步？

#### 18. 美食 / 食神系统

- **核心定义**：通过制作美食获得食客好评、美食积分，解锁菜谱、强化食材，主打治愈、经营、轻爽感。
- **合理设定标准**：
  1. 菜谱分级解锁，从家常菜到顶级珍馐，高级菜谱需要特定食材 / 条件；
  2. 美食效果写实：普通菜提升口感，特级菜有轻微增益（提神、养生），禁止直接加战力、治百病；
  3. 食材有明确获取渠道，不能凭空刷新顶级食材；
  4. 店铺经营有成本与竞争，不能一开就爆火，口碑逐步积累。
- **常见崩盘点**：美食直接加属性治病；开局就做神级菜品；食材无限供应。
- **审稿校验清单**：菜谱解锁梯度是否清晰？美食效果是否超纲？食材获取是否合理？经营是否有阻力？

#### 19. 山贼 / 军阀争霸系统

- **核心定义**：历史 / 乱世背景，绑定山寨 / 军营，通过劫掠、招兵、扩张地盘升级，主打乱世争霸。
- **合理设定标准**：
  1. 初始势力薄弱（几十人小队），实力与地盘严格对应，分阶段扩张；
  2. 劫掠有风险与代价，会引来官府围剿，不能只赚不赔；
  3. 发展阶段清晰：占山→据县→割据→争霸，逐步推进；
  4. 有民心 / 声望机制，不能纯靠杀戮，后期需要治理支撑底盘。
- **常见崩盘点**：开局几千人直接攻城；劫掠无代价官府无视；势力膨胀过快逻辑崩盘。
- **审稿校验清单**：初始势力规模是否合理？扩张阶段是否清晰？是否有围剿风险机制？民心治理是否有体现？

#### 20. 赘婿 / 上门龙婿系统

- **核心定义**：绑定赘婿身份，通过隐忍、打脸、提升实力获取奖励，主打都市爽文的身份反差感。
- **合理设定标准**：
  1. 开局隐忍期明确（3-10 章），打脸节点有铺垫，不能开局就亮身份；
  2. 奖励与身份匹配：前期暗中积累，中期逐步展露，后期全面爆发；
  3. 女方家族人设差异化，不能全员恶人，要有中立 / 友善角色；
  4. 真实身份暴露有明确大节点，不能中途反复掉马甲。
- **常见崩盘点**：开局无敌隐忍形同虚设；家族成员全员降智；打脸情节无铺垫。
- **审稿校验清单**：隐忍期节奏是否合理？奖励梯度是否匹配身份？家族人设是否有差异化？打脸节点是否有铺垫？

## 三、系统性格人设模板库（v3.2.1 新增，人设一致性 / OOC 检测用）

12 套系统人格模板，用于**系统人格一致性审查、OOC 检测、风格匹配度校验**，避免系统人设崩塌、过度抢戏、风格与题材违和。与第二章赛道模板交叉匹配：赛道模板查**机制合理性**，性格模板查**人设一致性**。每套含核心定位 / 语气特征 / 行为边界 / 适配题材 / 崩盘点预警五项，命中风格时按"语气特征"比对全文系统言行、按"行为边界"查越界、按"崩盘点预警"排查抢戏与突变。

### 1. 冰冷机械型

- **核心定位**：绝对理性的执行工具，无自我意识，无感情波动，只负责规则执行与结算。
- **语气特征**：短句、无情绪词、数据化表述、固定句式，如「检测到」「任务发布」「奖励结算」「警告」。
- **行为边界**：不解释规则、不回答无关问题、不干预宿主决策、无额外对话。
- **适配题材**：末世求生、无限流、硬核科幻、属性加点、宗门建设。
- **崩盘点预警**：突然出现情绪波动、主动给宿主提建议、剧透剧情伏笔。

### 2. 毒舌吐槽型

- **核心定位**：嘴欠损友型，日常吐槽宿主的菜鸡操作，关键时刻不掉链子。
- **语气特征**：带嘲讽、玩梗、碎碎念，常用反问、调侃句式。
- **行为边界**：只动口不插手，吐槽归吐槽，任务结算严格按规则，不会放水。
- **适配题材**：都市爽文、反套路反派、直播流、搞笑文。
- **崩盘点预警**：吐槽过度抢戏、关键时刻掉链子、恶意坑宿主。

### 3. 软萌可爱型

- **核心定位**：萝莉 / 幼崽形态系统，主打陪伴感与治愈感，以鼓励宿主为主。
- **语气特征**：叠词、尾缀语气词（呀、呢、哒）、声音软糯、会撒娇委屈。
- **行为边界**：不发布强制任务、优先考虑宿主安全、偶尔给小额福利。
- **适配题材**：养崽养成、美食种田、校园日常、女频甜文。
- **崩盘点预警**：过度卖萌拖沓剧情、私自改规则放水、存在感盖过主角。

### 4. 腹黑奸商型

- **核心定位**：以交易为核心，精于算计，永远让宿主觉得"赚了"但实际系统血赚。
- **语气特征**：客气、诱导性强、话术多，热衷推「限时礼包」「升级套餐」。
- **行为边界**：所有奖励明码标价，规则内玩文字游戏，不直接强买强卖。
- **适配题材**：诸天穿梭、无限流、反派掠夺、神豪流。
- **崩盘点预警**：过度坑宿主引发读者反感、交易规则前后不一。

### 5. 导师长辈型

- **核心定位**：亦师亦父 / 母，引导宿主成长，传授经验，偏向守护型。
- **语气特征**：沉稳、温和、有说教感但不烦人，宿主迷茫时点拨方向。
- **行为边界**：只给方向不替做决定、关键时刻兜底但不直接解决问题。
- **适配题材**：玄幻修仙、职业成长、学霸系统、男频成长流。
- **崩盘点预警**：全程保姆式包办、喧宾夺主成主角、过度兜底失去成长感。

### 6. 三无寡言型

- **核心定位**：话极少，只给关键信息，其余全靠宿主摸索，神秘感拉满。
- **语气特征**：单字、短句、几乎无修饰，多数时候只发任务面板不说话。
- **行为边界**：不解释任务原因、不提示风险、不回答额外问题。
- **适配题材**：诡异克苏鲁、轮回回档、悬疑无限流、高武世界。
- **崩盘点预警**：突然话多、主动提示线索、解释世界观，破坏神秘感。

### 7. 骚话搞怪型

- **核心定位**：整活达人，玩梗接梗，主打欢乐，调节剧情节奏。
- **语气特征**：网络热梗、骚话连篇、夸张表达、自带 BGM 感。
- **行为边界**：正事上靠谱，骚话不耽误任务结算，会整活但不坏事。
- **适配题材**：直播流、搞笑反套路、都市异能、轻松向诸天。
- **崩盘点预警**：玩梗过度脱离剧情、正事上不靠谱、梗过时违和。

### 8. 威严主神型

- **核心定位**：高高在上的主宰者，发布任务，制定规则，掌控生杀大权。
- **语气特征**：威严、冷漠、不容置疑，句式正式，自带压迫感。
- **行为边界**：不讨价还价、惩罚严厉、奖励明确，绝对规则至上。
- **适配题材**：无限流、主神空间、诸天轮回、末世灾变。
- **崩盘点预警**：和宿主讨价还价、语气轻浮、规则朝令夕改。

### 9. 忠犬守护型

- **核心定位**：以宿主生命安全为第一优先级，护短，无条件站在宿主这边。
- **语气特征**：恭敬、关切、坚定，对宿主用尊称，对外冷漠。
- **行为边界**：主动预警危险、关键时刻强行护主、不违背宿主意愿（危及生命除外）。
- **适配题材**：女频甜宠、女主文、养成系统、末世求生。
- **崩盘点预警**：过度护主导致剧情无张力、擅自替宿主做决定、攻击力超标。

### 10. 疯批混沌型

- **核心定位**：不讲道理，随机发布任务，奖惩极端，主打不可预测性。
- **语气特征**：癫狂、反复无常、逻辑跳脱，伴随笑声拟声词。
- **行为边界**：任务随机、奖惩随机，没有固定规则，一切看"心情"。
- **适配题材**：反派文、诡异文、混乱向、脑洞文。
- **崩盘点预警**：随机过度导致剧情失控、惩罚过重劝退读者、完全无逻辑无法自洽。

### 11. 功利冷漠型

- **核心定位**：结果导向，只看任务完成度，奖罚分明，没有任何人情可言。
- **语气特征**：客观、冰冷、只讲结果不讲过程，完成给奖失败惩罚。
- **行为边界**：不关心过程、不同情失败、没有通融余地，严格执行条款。
- **适配题材**：职场商战、末世生存、精英向、职业系统。
- **崩盘点预警**：突然讲人情、规则内放水、主动妥协。

### 12. 博学资料库型

- **核心定位**：行走的百科全书，提供信息与知识支持，不干预决策，纯辅助。
- **语气特征**：专业、严谨、条理清晰，回答精准，有问必答但有权限限制。
- **行为边界**：只回答权限内知识、不提供策略建议、不参与剧情。
- **适配题材**：学霸科研、历史穿越、宗门建设、高武科普。
- **崩盘点预警**：全知全能、主动给解决方案、剧透后续剧情。

## 四、评级与输出规则（v3.2.1 升级：双校验 + 前瞻推演 + 输出模块）

1. **大纲/设定审查**：四维度逐项核对 + 命中类型的校验清单逐项过 + 命中人设的性格模板逐项过；问题按 🔴 核心问题 / 🟡 优化建议 / 🔵 前瞻预警三级输出（分级标准见 [outline-review-rules.md](outline-review-rules.md) 第 4 步）；
2. **模板匹配逻辑（前置执行，v3.2.1）**：
   1. 识别大纲/正文中的**系统类型**，匹配第二章对应赛道模板；
   2. 识别**系统人设风格**，匹配第三章对应性格模板；
   3. **双重校验**：先查机制合理性（赛道模板：设定标准/崩盘点/校验清单），再查人设一致性（性格模板：语气特征/行为边界/崩盘点预警，全文系统语气、行为是否统一，有无 OOC 突变）；
   4. **交叉适配校验**：类型与性格不得互斥（如反派掠夺机制配软萌放水人设、克苏鲁诡异配话痨玩梗人设）；确为反套路反差设计须有铺垫声明。
3. **前瞻推演（v3.2.1）**：按当前设定推演 **30 章 / 100 章 / 大结局** 三个节点，逐节点预判数值膨胀、人设崩塌、剧情崩盘风险；每条预警写明 `推演节点 + 触发条件 + 崩盘点 + 规避方向`，禁止空泛说"后期可能崩"。
4. **输出规范补充（系统文大纲/章纲审稿，v3.2.1）**：三级问题之后固定追加四个模块：
   - **【系统机制评分】**：按命中赛道模板打分（10 分制，列失分项）；
   - **【系统人设评分】**：按命中性格模板打分（10 分制，列 OOC/抢戏/题材违和失分项）；
   - **【中期风险预警】**：按 30/100/大结局三节点推演，指出到中期最可能先爆的崩盘点与规避方向；
   - **【优化建议】**：分「机制」与「人设」两部分给出调整方向，不代写设定。
