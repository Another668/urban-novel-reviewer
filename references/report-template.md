## 输出规范

1. **所有问题必须引用原文**（具体句子 + 段落/行号），禁止"有些地方节奏偏慢"这类无定位表述。
2. **每条问题附可直接使用的改写文本**，不说"加强描写""增加冲突"这类空话。
3. **评分必须有依据**，对照记忆文档或外部技能规则，不得无理由给分。
4. **问题分级合理**：高优3-5条（影响发布/硬伤穿帮），中优3-6条（有损质感），低优若干（打磨）。
5. **亮点不少于2条**：审计是辅助不是否定。
6. **调度标注**：每条问题末尾标注 `[调度:技能名]` 或 `[内置规则]`，让作者知道判定依据来源。
7. **多章对比审**额外输出：跨章数值曲线表、伏笔时间线表、重复桥段克隆清单（对照近5章）、人物关系演进表。
8. **发布前门禁审**额外输出平台门禁清单（G0合规红线/G1字数/G2对话占比/G3话疗/G4战斗/G5循环/G6节奏）逐项✅⚠️❌（见上方🚨门禁表），末行给明确结论：`✅ 可发布` / `⚠️ 修N项后发布` / `❌ 暂缓发布`。
9. **六大审查不可省略**：触发"审稿"时 a)逻辑/b)人物/c)对话/d)模板化/e)合规/f)AI味 六项必须逐项给结论（无问题标 ✅ 并简述依据），禁止跳项。
10. **合规未命中声明**：G0 未发现红线时也必须输出"未发现红线问题（AI审稿不替代平台审核，发布前以目标平台最新规则为准）"。
11. **伏笔专项输出（v3.4.0）**：命中伏笔类需求时，【核心问题】中伏笔专项问题标 **【伏笔】** 前缀、【剧情风险预警】中高风险遗忘伏笔标 **【伏笔预警】**、报告末尾【专项审查附录】下追加伏笔追踪子段（模板见下方"伏笔追踪专项附录"）；快速审稿不输出完整追踪表；未命中伏笔需求时仅后台基础扫描、**输出与原模板完全一致**；`foreshadow_base` 未传入时跳过精度对比模块。

## 伏笔追踪专项附录（v3.4.0，命中伏笔类需求时在报告末尾追加）

```markdown
### 🔎 伏笔追踪专项结论（建议级，不影响总分）

**【本章新增预埋】** X 条
| 编号 | 大类·小类 | 摘要 | 优先级 | 锚点 |
|------|----------|------|--------|------|
| F-001 | 实体类 F1 物品道具 | …… | 高 | 第X段「原文……」 |

**【全局未回收】** X 条（含到期预警 X 条、遗忘预警 X 条、台账膨胀 X 条）

**【逻辑冲突】** X 条
- [冲突类型] 台账 F-00X（第X章埋设）记录为 A，正文第 Y 段写为 B → 判级 + 回收计划建议

**【原生系统精度对比报告】**（仅传入 foreshadow_base 时显示；未传入自动跳过）
- 原生识别 N 条 / 本专项 M 条 / 重合 K 条 → 差异条目归属与采信建议

**【全书伏笔追踪表】**（Markdown 台账全文，可直接存档；快速审稿降级不输出）
```

降级规则：快速审稿仅输出核心问题与【伏笔预警】；深度审稿（precise）额外输出精度对比与完整追踪表；所有伏笔诊断**只提建议**（回收时机、埋线方式调整），不代写伏笔剧情。

## 边界情况

- **文本<500字**：仍全维度审，注明"样本小，部分维度仅供参考"。
- **多章>10000字**：先整体扫描定位，再对关键段落精细审。
- **作者提供背景与记忆文档冲突**：以作者当场声明为准，但提示其同步更新记忆文档。
- **刻意为之的写法**（角色口癖、设定好的反差、作者风格化表达）：不判问题，必要时在亮点中说明。
- **作者要求"只标问题不改写"**：跳过✅建议文本，只给❌定位+💡思路。
